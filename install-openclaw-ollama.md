# Install OpenClaw and Ollama on Ubuntu

## Environment
- OS: Ubuntu Server 24.04
- Runtime: OpenClaw
- Local model runtime: Ollama

## Steps
1. Install required packages
2. Install Ollama
3. Pull and test model
4. Install/Open OpenClaw
5. Connect OpenClaw with local model

## Notes
This guide is based on my personal setup and troubleshooting process. Some steps may change depending on the OpenClaw version and system environment.
