# Troubleshooting Notes

## OpenClaw device not connected
Checked network connection, local runtime status, and device approval flow.

## Ollama model not responding
Verified Ollama service status, model list, and local API availability.

## VNC black screen / gray screen
Checked desktop session config, VNC startup script, and user permission.

## Remote connection issue
Verified firewall, EC2 security group, public IP, and service listening port.
